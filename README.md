# Goodlite Editor 🚀

A lightweight, lightning-fast code editor built purely in Python using `tkinter` and the standard library, specially optimized for low-spec hardware and low RAM usage.

## ✨ Features

- **Tabbed Interface**: Manage multiple files seamlessly with clean tabs.
- **Syntax Highlighting**: Supports syntax coloring for 20+ programming languages.
- **Live Terminal**: Integrated subprocess terminal to run scripts instantly (Python, JS, HTML, etc.).
- **Smart Autocomplete**: Sublime-Text style local document word cache with Tab completion via native popup listbox.
- **Performance Focused**: Minimal RAM footprint (~25-40 MB) with a blazing-fast startup time.
